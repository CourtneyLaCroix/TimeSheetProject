# TimeSheetProject
##Custom timesheet to assist with logging bi-weekly hours

Goals:
  - reduce time spent recording hours on due date
  - increase hour accuracy by making daily logging easier.
  - exports a csv at the end of the week for submittion to HR

Resources:
  - FileIO and application UX/UI design all in java

input:
  -Job name
  -hours worked

output:
  - date
  - jobName
  - Hours worked
